# Security policy

Report suspected vulnerabilities using GitHub's [private vulnerability reporting form](https://github.com/conao3/rust-sellaite/security/advisories/new). Keep vulnerability details out of public issues, pull requests, and discussions while the report is being investigated.

Include the affected version or commit, the impact, and enough detail for the maintainers to reproduce the issue. Remove credentials and personal data from any logs or screenshots. Use the private advisory thread for follow-up and to coordinate disclosure.

See the [README security section](README.md#security) for the deployment threat model.
